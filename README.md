# FreeRerolls

A tiny mod for Brotato that makes shop rerolls free.
一个为《土豆兄弟》制作的小型 Mod，将商店刷新设为免费。

## 说明 / Description

- 商店刷新不再消耗金币。
- Shop rerolls no longer cost gold.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=2958802806
- 兼容 / Compatible: Brotato 1.1.0.0, ModLoader 6.2.0
